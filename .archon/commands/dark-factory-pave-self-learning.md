# Dark Factory PAVE Self Learning

Self-learning is a dedicated PAVE task after the work item, not a hidden final thought.

Assess:

1. Which generated artifacts were used as generated.
2. Which artifacts were manually changed.
3. What manual changes imply about missing instructions, weak prompts, stale knowledge, or repo conventions.
4. Which learnings should be captured in WTG Second Brain through sbkb.

Writeback policy:

- Use sbkb for durable learning capture.
- Keep wtgkb as read-mostly current-task knowledge.
- Record the learning assessment and sbkb writeback result in the factory portal.
